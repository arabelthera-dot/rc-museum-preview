ПРАВИЛО ПРИВЯЗКИ ДАТ — ДЛЯ ИСКУССТВА ОСЛАБЛЕНО (Сергей, 04.09.2026, дословно): «Для музея искусства нет надобности привязываться всегда к каким-то датам, потому что у разных художников могут быть несколько интересных картин, которые будут размещаться, и они могут не привязываться к датам. Для этого конкретного музея это не обязательно». Вывод: [У]-условные слоты — норма этого музея, художник может появляться в календаре несколько раз с разными картинами; формулы «в этот день» при [У] по-прежнему запрещены.

КАЛЕНДАРЬ: январь УТВЕРЖДЁН Сергеем 04.09.2026 («Да, январь оставляем. Утверждаю»). Файл: pilot-iskusstvo/calendar-january.md. Дальше — месяцы по очереди, каждый показываю табличкой до производства.

Страница 1 января (Кустодиев «Ёлочный базар», 1918) — концепция УТВЕРЖДЕНА 04.09.2026. Хук утверждён: «Самую весёлую ярмарку русской живописи написал человек, прикованный к инвалидному креслу» (факт: паралич с 1916, НЕ «слепой» — предложение Сергея «слепой художник» я вернул с поправкой, Сергей принял). Драматургия страницы: праздник вопреки. Каркас эталона «Девятый вал» + УТВЕРЖДЁННЫЕ 6 добавок: шторка «эскиз → полотно» (M-47), ставка до ответа (M-30, «сколько людей на базаре?»), звуковой слой ярмарки (M-04, только чистые бесплатные звуки — или не делаем), чат по подлинным цитатам с плашкой «источник» (M-74), развилка судьбы «1918: что пишешь?» (M-15), праздничный режим 1 января (M-46, снегопад в полях страницы, не поверх картины).

«Девятый вал» — УТВЕРЖДЁН Сергеем 2026-07-28. Это эталон зала, с него берётся структура для всех следующих страниц. Состав: hero + глубокий зум с тайлами (скан 5815px) + 3 искорки + игра «найди деталь» + ролик 61 сек + аудиогид RU/EN + «В это трудно поверить» (5 фактов) + статья + «Разбор для внимательных» (лессировки, композиция, Тёрнер, путь полотна, хронология одной ночи) + сравнение с мировой живописью (Жерико, Хокусай — визуальное, не текстом) + викторина 4 вопроса + шарада + чат с художником + EN-версия.

Аудиогид эталона — 7 мин 31 сек (не минутный!): вся страница кроме интерактива, 8 глав с тайм-кодами, нативный плеер с перемоткой. Правило «ролик ≠ аудиогид» — в скилле.
