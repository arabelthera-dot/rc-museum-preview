Решение Сергея 04.09.2026 (дословно): «Для музея искусства нет надобности привязываться всегда к каким-то датам, потому что у разных художников могут быть несколько интересных картин, которые будут размещаться, и они могут не привязываться к датам. Для этого конкретного музея это не обязательно». Отсюда: [У]-слоты — норма, художник может встречаться в году несколько раз с разными картинами. При [У] формулы «в этот день» запрещены (museum-art).

Привязка даты: [Р] рождение художника · [И] событие · [К] календарный якорь · [У] условная (картина без точной даты).

Механика по умолчанию — эталон зала Айвазовского: глубокий зум с деталями + игра «найди деталь» ✅ (движок уже есть). Где скан слабее 2500 px — ограниченный зум с честной пометкой (профиль museum-art).

Страниц пока нет ни у одного дня: колонка «куда ведёт» появится при производстве. Есть только три страницы зала Айвазовского (июль, май).
