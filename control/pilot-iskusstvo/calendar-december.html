# Календарь — декабрь
## Музей русского искусства

**Статус:** состав собран 08.10.2026 (31/31), на «да» Сергея 08.10.2026 («Я по всем
музеям на все 365 дней утвердил дни календаря»). Даты — по НОВОМУ стилю. 🔎 — сверка по
русским источникам до сборки страницы. Привязка: **[Р]** рождение · **[И]**
событие · **[К]** календарный якорь · **[У]** условная (для искусства привязка
не обязательна — решение Сергея 04.09.2026; художник может входить в год
несколько раз с разными картинами).

Механика по умолчанию — эталон зала Айвазовского (зум + «найди деталь» ✅);
в месяце механики разнообразятся по `docs/interactive/REGISTRY.md` — состав и хуки
не меняются, меняется только колонка «Механика».
