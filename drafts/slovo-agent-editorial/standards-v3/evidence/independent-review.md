3. В проверенной HTML отсутствуют canonical и OG. Для окончательной выдачи страницы по G3 это долг; noindex у рабочего черновика корректен.

Этот read-only отчёт не подтверждает паспорт/профиль, SHA комплекта медиа, права, окончательную строгую сдачу, реальную геометрию на 320/360/390/768/1440, проигрывание аудио и независимые функции всех медиа.
