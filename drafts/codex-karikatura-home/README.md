# Отдельный вариант главной «Острее пера»

Прямое поручение Сергея 06.09.2026: сделать параллельно, не заменяя работу другого агента.

Использованы концепция, существующие страницы и календарь музея. Функции архитектурной главной: предметный вход, мини-разбор, истории, календарь, школьный маршрут, поддержка, сведения о музее. Главная не является страницей дня: счёт /100 и дневной медиапакет к ней не приписаны.

Варианты хука: «Смешно. А почему?»; «Император оказался в бочке»; «Кто распоряжается на этом листе?». Для обложки выбрано наблюдаемое действие с оригинала; первый вариант — вход в разбор.

Статус: предварительное превью для сравнения. Концепция задаёт русскую и советскую коллекцию; иностранные листы в обложку и карточки этого варианта не добавлены.
