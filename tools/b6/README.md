# `tools/b6/` — общий прогонщик браузерных доказательств B6

> Наряд `b6-sborshchik-obshchiy-claude4-2509`, исполнитель `claude4`, 26.09.2026.
> Прогонщик вынесен из папки одного музея в общее место превью, чтобы им мог
> пользоваться любой музей, а не только автор.

## Что здесь лежит

| Файл | Что это |
|---|---|
| `run-b6.mjs` | производитель конверта `schema_version=1` для `tools/interactive_contract.py` |
| `plan-template.mjs` | размеченный шаблон плана: восемь сценариев, что каждый обязан доказать |
| `plans/exp-nikitin-1468.mjs` | рабочий пример: план под чужую живую страницу (`muzei/pervoprohodcy/exp-nikitin-1468.html`) |

`run-b6.mjs` побайтово совпадает с прогонщиком, который уже лежит в корне
(`docs/agents/tasks/2026-09-23-b6-runner/run-b6.mjs`), и с прогонщиком карикатуры
Кодекса (`tools/checks/karikatura-2509/run-b6.mjs` на ветке
`codex/karikatura-audit-fixes-2509`). Разных реализаций теперь не три, а одна:
здесь она лежит там, где её найдут, — рядом со страницами, которые она проверяет.

## Как запустить

Нужны Node 22, `PLAYWRIGHT_CDP` (общий браузер, в этом контейнере
`http://chrome:9222`) и Playwright. Из корня превью:

```sh
RC_PLAYWRIGHT_MODULE=/home/agent/projects/russian-civilization/node_modules/playwright/index.mjs \
PLAYWRIGHT_CDP=http://chrome:9222 \
node tools/b6/run-b6.mjs . muzei/<музей>/<страница>.html tools/b6/plans/<план>.mjs <новый-каталог> --install
```

`ROOT` — каталог, внутри которого лежат страница и её локальные зависимости
(обычно `.`). Каталог проверки обязан быть новым: прогонщик не перезаписывает
готовый конверт и ставит `.run-lock`. `--install` кладёт штатный
`<страница>.html.interactive.json` — тот самый, который читает `audit-pages.py`.
Без `--install` конверт остаётся в `<новый-каталог>/browser.interactive.json`.

Возврат: `0` — все восемь кодов пройдены, `1` — FAIL или неполнота,
`2` — ошибка запуска. **Код 0 не равен сдаче музея.**

## Как написать план под свою игру

План — это `.mjs`, который экспортирует `scenarios`: восемь функций по числу
кодов B6. Начни с `plan-template.mjs`, он размечен.

- `step(label, fn)` — действие; `check(label, actual, expected)` — утверждение.
  `check` сравнивает строго (`deepEqual`), при расхождении сценарий падает.
- Функции получают `{page, context, check, step, width}`.
- Импортируемые помощники перечисли в `dependencies` относительно файла плана —
  они войдут в SHA-конверт.
- Пустая функция — FAIL, отсутствующая — НЕ ПРОВЕРЕНО. **Подменять сценарий
  `check(true, true)` ради зелёного нельзя**: это брак выдачи.
- Порядок утверждений внутри сценария важен: первое упавшее прекращает сценарий,
  поэтому сначала кладут то, что должно пройти, а диагностическое — последним.
- Если механики на странице нет вовсе (нет викторины, нет сброса), сценарий не
  пишут: код честно остаётся НЕ ПРОВЕРЕНО, а причина уходит в `omissions`,
  как в `docs/agents/tasks/2026-09-23-b6-runner/komsomolets-plan.mjs`.

Внешняя сеть блокируется: любой запрос за пределы `ROOT` — ошибка сценария.
Хеши страницы, плана, прогонщика, всех запрошенных локальных ресурсов, снимков и
наблюдений входят в конверт; изменение любого входа обесценивает весь пакет.

## Что прогонщик доказать не может

Ограничение не прогонщика, а самого договора `tools/interactive_contract.py`:
`evaluate()` возвращает НЕ ПРОВЕРЕНО на **все восемь кодов сразу**, если у страницы
есть хотя бы один внешний или корневой (`/…`) `script[src]` или `link[rel=stylesheet]`.
Такой странице пакет не поможет — сначала убирают внешний ресурс.

Проверено машиной по снимку `tools/audit-baseline.json` (46 страниц с долгом B6, 26.09.2026):

- **16 страниц** заблокированы навсегда: 16× `fonts.googleapis.com/css2`,
  5× `cdn.jsdelivr.net/npm/three@0.160/build/three.min.js`;
- **40 страниц** не имеют `<noscript>` — код `nojs` на них честно не пройдёт,
  пока страница не получит текстовый эквивалент вместо пустой обещанной игры;
- **42 страницы** не объявляют реестр наград (`museum-score-manifest`),
  без него нечего доказывать по коду `score`.

Ни одна из 46 страниц не проходит все три условия сразу. Значит, долг B6
снимается не прогонщиком, а правкой страниц — и это работа владельца музея,
а не общих инструментов. Прогонщик снимает другое: он превращает «НЕ ПРОВЕРЕНО»
в проверенный ответ — «чисто» там, где страница здорова, и «НЕ СОБЛЮДЁН» там,
где дефект настоящий.

### Проверка на живой странице

26.09.2026, `muzei/pervoprohodcy/exp-nikitin-1468.html` (чужой музей), план
`plans/exp-nikitin-1468.mjs`, пакет установлен штатным `--install`:

| | нарушений | НЕ ПРОВЕРЕНО |
|---|---:|---:|
| без пакета | 2 | 8 |
| с пакетом | 3 | 0 |

Семь кодов B6 стали «чисто». Восьмой (`nojs`) — «НЕ СОБЛЮДЁН»: у страницы нет
`<noscript>`, без JavaScript игровые блоки пусты. Пакет не узаконил дефект и не
спрятал его за НЕ ПРОВЕРЕНО, а предъявил. Два прежних нарушения (`счёт из 100`,
`хук`) пакет не трогал — это работа владельца музея.

Страница `muzei/pervoprohodcy/exp-bering-1728.html`, названная в наряде, доказана
быть не может: она тянет `https://fonts.googleapis.com/css2…` как таблицу стилей.
Прогон это подтверждает машинно — все восемь сценариев падают с
`Unpinned external request: https://fonts.googleapis.com/css2…`.
