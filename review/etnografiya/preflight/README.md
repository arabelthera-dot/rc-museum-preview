## Результат проверки

365 уникальных дат; точных повторов заголовков нет. Из них 69 строк содержат адрес предметной карточки, 174 — запись, альбом или иное описание, 122 новых строки — общую обзорную опору. Эти категории описывают структуру ссылок и не доказывают историческую или производственную готовность. Находка безмена конкретизирует одну тему, но ещё требует подготовки медиа и модели.

Проект навыка прошёл штатный `quick_validate.py`. Проверка календаря воспроизводится командой `python3 audit_calendar.py`; [результат и хеши исходных месяцев](calendar-audit.json). [Проверка медиа](media-check.json) фиксирует размеры и SHA-256 реально просмотренных файлов. Исходные JSON, HTML, Excel и PDF календаря не менялись; новая редакция ещё не выдаётся за согласованный годовой комплект.

## Ближайшая работа

Продолжить предметный подбор для 122 строк и конкретизацию альбомных источников. Для прялки найти разрешённый крупный план с читаемой сценой; для касимовки — документированную схему и подходящую запись. Рассматривание, дом и звук испытываются отдельными работающими стендами в существующей зоне предпросмотра по мере готовности их материалов.

Перед проектированием первой страницы нужен принятый профильный навык: общий `museum-core`, §1 (`rc-museum-production/standards/museum-core.md`) прямо требует: «До его утверждения нельзя выполнять ШАГ 0, проектировать или собирать первую страницу музея». Это ограничивает начало страницы; редакторская и предметная подготовка продолжается. Подготовленный выше текст навыка — конкретный материал для этой приёмки.

Существующий [демонстратор этнографии](https://arabelthera-dot.github.io/rc-museum-preview/review/etnografiya/demo/) доступен, HTTP 200 проверен 09.09.2026. Он не является новым результатом этого пакета и не заменяет испытания трёх запланированных опытов.
