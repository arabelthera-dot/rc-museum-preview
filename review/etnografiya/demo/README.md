Граница: одна фотография, три увеличиваемые детали, одна развилка с объяснением, локальные семейные отметки. Без новых записей, платных сервисов, регистрации, серверного хранения и тиражирования. Общие музеи и правила не изменены.

Профиль demo-v1: обязательны атрибуция кадра, три детали с оригиналом, ошибочный и успешный выбор, повтор, личные отметки, сохранение и восстановление, скачивание, источники, узкий экран, доступность клавиатурой. Дата выпуска, баллы, ролик, аудиогид, календарь неприменимы к данной проверке концепции. Профиль не претендует на замену production-профиля.
