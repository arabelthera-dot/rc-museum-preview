# Хук: три варианта до сборки

Все варианты — для уже выбранного ларца, без изменения состава музея. Прежний HTML не правился. Норма — 130–160 знаков; риторического вопроса в конце нет.

1. **150 знаков.** Пять замков защищали дубовый ларец, а железо на крышке превращалось в кружево. Внутри — восемь ящиков: русское мастерство видно по обе стороны крышки.
2. **157 знаков.** Восемь ящиков скрыты за крышкой ларца 1750 года. Снаружи — железные полосы и ажурный узор; внутри — устройство, которое открывается только при смене ракурса.
3. **159 знаков.** На железе сохранились год и имя, за крышкой — восемь ящиков. Ларец 1750 года позволяет рассмотреть работу русских мастеров, даже когда их биографии неизвестны.

Авторский выбор — первый. В нём встречаются защита, орнамент и скрытое устройство. Второй больше похож на описание интерфейса, третий смещает центр истории к биографии, для которой не хватает сведений. «Кружево» — зрительное сравнение просечного железа, не материал предмета. Источники чисел — C04/C05 в `materials.json`.
