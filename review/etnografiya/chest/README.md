# За пятью замками

Полная сборка страницы ларца-подголовника 1750 года из Русского музея, ОНИ/М-4, для показа Сергею по прямому поручению 09.09.2026.

`index.html` — собранный файл. `full-source.html` — исходник; `build.py` встраивает фотографии и шрифт. Музейные общие компоненты встроены из действующих файлов без изменения их кода. Медиа лежат в `media/`: аудиогид, ролик 1920×1080 со звуком и субтитрами, тексты. Видео и аудио загружаются по действию пользователя.

Порядок страницы: музейный верх → ролик → аудиогид → открытие ракурсов → рассматривание → рассказ → факт и версия → мировой контекст → проверка → итог и диплом → календарь → продолжение. Счёт 40+20+20+20=100, повтор не начисляет очки, сброс начинает новый проход.

Паспорт — `issue.json`. Проверки текущего HTML — `checks/full/`. Старые `acceptance.json`, `checks/desktop.png`, `checks/mobile.png` и `production/checks.json` относятся к предыдущим этапам и не доказывают приёмку этой сборки.

Прямая команда владельца о работе на имеющихся материалах — `production/owner-direction-2026-09-09.txt`. Письма не отправлялись. Атрибуция и статусы источников сохранены; полученная лицензия не заявляется. Общий реестр принятых профилей не изменён: строгая формальная регистрация нового профиля/эталона остаётся отдельным условием, её нельзя приписывать текущему результату.

Сценарные документы в `production/` фиксируют этап до сборки. Фактическая длительность видеоролика 82.368 с; запись аудиогида проверяется по метаданным файла. Голос синтезирован (ru-RU-DmitryNeural).
