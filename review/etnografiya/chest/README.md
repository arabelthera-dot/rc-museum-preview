# За пятью замками

Полноценный рассказ о ларце-подголовнике 1750 года для просмотра Сергеем после отклонения схематических стендов.

Открывать index.html. Самодостаточный файл: фотографии и шрифт встроены; общий музейный блок поддержки встроен без изменений из assets/museum-support.js.

Сборка: `/usr/bin/python3 build.py`. Исходник — story.html, цвета и интервалы — tokens.css, подлинные фотографии — media/. Публичная научная статья: https://rghpu.ru/uploads/catalogfiles/7984_2022_2_2_vestnik.pdf (Г. А. Пудов, 2022, с.169–178). Прямое извлечение JPEG, без дорисовки.

Проверены мобильный и настольный размеры, открытие фотографий, исходный размер, Esc, переключение ракурсов и ответ на предметный вопрос. Скриншоты — checks/, пределы проверки — acceptance.json. Полный публикационный допуск музейной страницы не заявлен.
