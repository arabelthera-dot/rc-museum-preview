# Сундук и начало семейной жизни: пакет для решения

Статус: **черновик для согласования**, 09.09.2026. Это подготовка двух самостоятельных опытов. Музейные страницы и стенды ещё не собраны. Утверждённые стандарты, календари и существующие HTML не изменены.

## Что предлагаю принять сейчас

| Решение | Рекомендация | Что это разрешит |
|---|---|---|
| Предметный навык первого музея | [«Русские вещи и мастерство»](skills/museum-things/SKILL.md) | Закрепить границу: материал, устройство, умение и созданная человеком вещь |
| Предметный навык второго музея | [«Русские обычаи и уклад»](skills/museum-customs/SKILL.md) | Закрепить границу: жизнь людей, отношения, местные практики и передача опыта |
| Художественная пара для испытания | **А1 «Железо становится узором» + Б1 «Кто помогал собирать новую жизнь»** из [шести вариантов](variants.md) | Уточнить предметы двух стендов внутри согласованной связки «сундук — приданое — новая семья» |

Первый кандидат — ларец-подголовник И. Чупятова из Русского музея. Он позволяет показать авторское мастерство на атрибутированном предмете. Это предложение конкретизации сундука, **не замена дня календаря**. Не связываем его с семьёй из второго опыта и не называем свадебным без свидетельства.

Для второго кандидата найдена запись личных воспоминаний. Она даёт возможность рассказывать через конкретного человека; полный исторический паспорт и ограничения — в [материалах](materials.md). Внутреннее название Б1 описывает замысел, не является готовым заголовком страницы.

## Где отрабатываем механизмы

Существующая зона `review/etnografiya/` в репозитории `rc-museum-preview`; новая изолированная папка `split/pair/lab/` — после выбора и обеспечения материалами. Это план расположения; такой папки и действующих стендов в этой поставке нет.

`museum-concept.md`, «Железное правило стадии», разрешает прототип механики и разведку кадров до принятия концепции. Это не разрешает назвать тестовую оболочку эталонной страницей. Для первой полноценной страницы действуют независимо: принятый тематический навык, полный календарь каждого нового музея, ШАГ 0, профиль типа и G0–G7. Пилотный сундук не становится 1 января автоматически; порядок эталонов с 1 января сохраняется.

Для А1 проверяем переход «целое → реальная деталь → целое», различимость узора и крепления, клавиатуру и тап. Для Б1 — выбор предмета, появление связи между людьми, пояснение свидетельства и полный сброс. Проверка понимания: посетитель после опыта объясняет одну особенность мастерства и одну человеческую связь. Наблюдений посетителей пока нет.

## Почему сейчас пакет, а не готовые стенды

1. После разделения объединённый навык помечен `superseded-by-split`; два новых текста подготовлены здесь для чтения. Они не установлены вместо действующих навыков.
2. Для А1 найден оригинал и источник изображения, но публичное использование музейного файла требует отдельного разрешения держателя. Крупные ракурсы соединений и внутреннего замка не получены. Модель устройства по одному внешнему фото была бы выдумкой.
3. Сборка Б1 зависит от выбранной художественной формы. Готовый в реестре движок последовательной сборки содержит храмовые ответы и для свободного комплектования приданого не подходит. Общий движок не переписан без согласования.

Паспорт прав не заменяем согласованием Сергея: разрешение на направление работы и разрешение держателя фотографии — разные основания. Отправка писем музеям не выполнялась.
