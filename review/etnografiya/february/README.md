# Февраль — Музей русской этнографии

Решение Сергея 08.09.2026: январь утверждён; перейти к февралю; этнографическое направление пробуем с возможностью переработки. Утверждение января не означает утверждения дизайна и всех механик.

Файлы результата: february.md, february.xlsx, february.pdf, index.html, february.json, february.csv. Пояснение вида музея: how-it-looks.md — три сценария, состояния экрана, результат посетителя и необходимые материалы. Механики пока не реализованы.

Проверено: 28 последовательных дат, пять непустых граф, 28 разных названий, все ссылки источников HTTP 200. Excel: целостность ZIP/XML, 28 строк и пять граф на основной вкладке. HTML: 1440, 390 и 320 px, поиск, оба фильтра, сброс и пустое состояние; без ошибок JS и выхода страницы за экран. PDF: 3 страницы, текст содержит все 28 дат. Проверки: verification.json и source-check.json.

Повторы января: точных повторов названий нет. Деревянная игрушка развивается через отдельный богородский предмет и парное движение; прочие темы продолжают общий календарный охват. Внутри февраля коклюшки 2 февраля и современная пелерина 28 февраля показывают инструменты и личную историю современной мастерицы.

Содержание источников просмотрено через поиск и открытие музейных страниц; прямая доступность всех 27 адресов проверена отдельно. Полные извлечения источников остаются локально для работы и не включены в пакет для публикации. Изображения, аудио, видео и права для музейных страниц пока не подбирались полностью. Нет оснований заявлять готовность страниц или тематического производственного профиля.

Сборка: content.py + render.py, стандартная библиотека Python 3. PDF создаётся через browser-check.js и Playwright. Повторно запускать проверки только после изменений.
