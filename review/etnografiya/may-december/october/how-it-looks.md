# Октябрь — примеры посещения

**Сватовство в двух шагах: договориться не сразу**

Сватовство не обязательно заканчивается первым визитом. Свадебная договорённость складывается по местному порядку, соединяя несколько действий и встреч. По белгородскому описанию расставить два этапа; открыть участников и предмет разговора каждого.

Атрибуция: Русские сёла Чернянского и Новооскольского районов; конкретное село и запись выбираются перед страницей.

**Смотр дома: брак связывает два хозяйства**

Перед браком знакомятся с другим хозяйством. Смотр дома показывает, что новая семейная связь касается повседневного устройства жизни. По выбранному локальному описанию составить маршрут знакомства с хозяйством; показывать только подтверждённые действия.

Атрибуция: Каталог локальных свадебных традиций. Берём только указанные русские традиции; обрядовые подробности требуют чтения карточки выбранного села.

**Рукобитье: соглашение становится видимым**

Рукобитье делает договорённость видимой. Жест становится частью местного свадебного порядка, по которому окружающие узнают о принятом решении. Найти жест и участников в конкретном описании; связать его с местом в свадебной последовательности.

Атрибуция: Каталог локальных свадебных традиций. Берём только указанные русские традиции; обрядовые подробности требуют чтения карточки выбранного села.
