# Декабрь — примеры посещения

**Полушубок: тепло при свободных руках**

Полушубок оставляет больше свободы для работы, чем длинная верхняя одежда. Длина вещи связана с движением человека в зимнем хозяйстве. Сравнить два документированных силуэта верхней одежды; сопоставить длину с выбранным занятием.

Атрибуция: Музейный альбом русских локальных костюмных комплексов; конкретный комплект уточняется перед страницей.

**Рукавицы: пальцы сохраняют тепло вместе**

Рукавица собирает пальцы в общем пространстве. Материал и следы износа помогают увидеть, как одежда служила рукам на морозе. Рассмотреть выбранные рукавицы, найти следы износа и сопоставить материал с местным описанием.

Атрибуция: Музейный альбом русских локальных костюмных комплексов; конкретный комплект уточняется перед страницей.

**Онучи: обувь начинается до лаптя**

Онучи входят в обувной комплект раньше лаптя. Несколько слоёв работают вместе — повседневная обувь начинается с подготовки самой ноги. По атрибутированной схеме собрать слои обувного комплекта; показать местный вариант без универсального рецепта.

Атрибуция: Музейный альбом русских локальных костюмных комплексов; конкретный комплект уточняется перед страницей.
