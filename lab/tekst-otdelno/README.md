# Текст отдельно от макета — прототип

Наряд `tekst-otdelno-ot-maketa-2709` (план перестройки, шаг 13), claude2, 27.09.2026.
Инструмент — `russian-civilization/tools/tekst-otdelno.py` (ветка `claude2/tekst-otdelno-2709`).
Принятые страницы и публикация не менялись: здесь только копия.

## 1. Где сейчас живёт текст страницы

Страница дня — самостоятельный HTML на 100–185 КБ. Разбор принятой `muzei/izobreteniya/day-26sep-pavlov.html`:

| где | сколько строк | что это |
|---|---|---|
| текстовые узлы HTML | 128 | заголовки, абзацы, подписи, `<title>` |
| атрибуты | 8 | `alt`, `aria-label`, `meta description/og:*`, `data-*` с текстом, тема `mailto:` |
| строки встроенных скриптов | 480 | интерактивы (вопросы, ответы, подсказки), настройка аудиогида, JSON-LD |
| **итого на странице** | **616** | |

Вне страницы: общие скрипты платформы `assets/*.js` — 702 строки интерфейса с кириллицей
(кнопки, подписи движков, календарь); `calendar-data.js` уже данные. Речь аудиогидов (mp3),
титры в видео и надписи на картинках — не текст страницы, этим способом не переводятся.

## 2. Формат

- `<страница>.layout.html` — та же разметка, вместо каждого текста метка `{{t:КЛЮЧ}}`
  (`text.NNN`, `attr.NNN`, `js.NNN`); в макете нет ни одного слова страницы.
- `<страница>.texts.json` — `{"texts": {"КЛЮЧ": "строка"}, "where": {...}, "kinds": {...}}`;
  текст хранится раскодированным (`&nbsp;` → неразрывный пробел), строки скриптов — как в исходнике.
- Сборка — `tekst-otdelno.py build МАКЕТ ТЕКСТЫ --out СТРАНИЦА`: обычный статический HTML
  (поисковику и читателю тот же файл, текст не подгружается скриптом). Перевод = второй
  словарь с теми же ключами (`texts.en.json`) и та же сборка.

## 3. Прототип: `day-26sep-pavlov`

Файлы здесь: `day-26sep-pavlov.layout.html`, `day-26sep-pavlov.texts.json`, собранная `day-26sep-pavlov.html`.

- Собранная страница **побайтно совпадает** с принятой (`cmp` — 0 отличий).
- Видимый текст в Chromium (`document.body.innerText`) одинаков на 390 и 1280 px:
  8514 и 8558 знаков, diff 0.
- Снимки `pavlov-{390,1280}-{do,posle}.png`: отличаются 7273 / 6095 пикселей — это шум самой
  страницы (анимация и видео): принятая страница против самой себя даёт 4340 / 7448 пикселей
  при том же HTML. Визуально — 1:1 в пределах собственного шума страницы.

## 4. Сколько страниц переводится этим способом

Изобретения, 18 страниц (16 дней + главная + календарь), машинная сводка — `report-izobreteniya.json`:

- **18 из 18** раскладываются и собираются обратно побайтно, видимый текст diff 0;
- **11 из 18** выносятся целиком (остаток — только регулярка `/ё/g` в поиске: это код, не текст);
- **7 из 18** мешают мелочи в коде:
  - шаблонная строка JS с `${…}` в интерактиве — 6 страниц по 1–2 строки
    (`luna1`, `buran`, `pilchikov`, `icebreaker`, `blinov`, `shukhov`): `…Расстояние ${d} м` —
    нужна функция `T("ключ", {d})` вместо склейки;
  - CSS `content:"открыть день →"` — `calendar.html`, 2 места: вынести подпись в разметку
    или в CSS-переменную из словаря.

## Что мешает и что дальше

1. 7 мест в коде интерактивов (выше) — правка движка/страницы, не перевода.
2. Общий словарь платформы для `assets/*.js` (702 строки) — отдельный `texts` на движок,
   иначе переведённая страница заговорит русскими кнопками.
3. Строки скриптов хранятся в JS-экранировании: переводчику нужен экранирующий редактор
   или функция `T()` в движках вместо литералов.
4. Сборщик черновиков `tools/rc-page.py new` уже собирает день из данных — естественный
   следующий шаг: пусть он пишет сразу пару «макет + тексты».
